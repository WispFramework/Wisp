# About Wisp Framework

!!! warning
    Wisp Framework is still in very active development and while it is absolutely usable, it is
    very much considered unstable and not suitable for production use.

    Parts of this documentation may be incomplete, outdated or describing features that are not
    yet fully implemented.

    **Please do not use Wisp in production unless you fully understand the security implications
    of doing so.**
